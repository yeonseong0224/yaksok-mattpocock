# 05: 후보 계산 모듈

**What to build:** 약속 설정, 제출된 슬롯, 기준 시각을 받아서 서로 겹치지 않는 최대 5개 후보(시작·끝 시각, 참석 가능한 참여자)를 돌려주는 순수 모듈이다. DB와 시계에 의존하지 않고, 후보 조회(08)와 확정(09)이 함께 쓴다. 화면은 없고 단위 테스트로 검증한다(보조 seam).

스펙: Implementation Decisions › 모듈 › 후보 계산 모듈. 규칙: RESULT-01-01/02, 02-01/02, 03-01, 04-01, 06-01/02, 07-01/02, TIME-05-02, TIME-07-01, TIME-08-02.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 후보 시작 시각은 30분 슬롯 경계이고, 구간은 시작 포함·끝 미포함이다
- [ ] 구간 전체가 하루 시간 범위 안에 있어야 한다. 자정을 넘기는 후보는 00:00~24:00일 때만 생긴다
- [ ] 약속 길이 전체에 걸쳐 연속으로 가능한 참여자만 센다
- [ ] 가능 인원이 2명 미만인 시각과, 기준 시각보다 이전에 시작하는 시각은 후보가 아니다
- [ ] 정렬: 가능 인원이 많은 순, 같으면 시작 시각이 빠른 순
- [ ] 정렬 순서대로 고르되 이미 고른 후보와 겹치면 건너뛰고, 최대 5개까지 고른다
- [ ] 후보가 없으면 빈 결과를 돌려준다
- [ ] 위 규칙마다 단위 테스트가 있고, 테스트 이름은 GLOSSARY 용어로 짓는다
