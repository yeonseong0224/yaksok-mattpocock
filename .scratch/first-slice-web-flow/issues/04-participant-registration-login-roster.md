# 04: 참여자 등록·로그인·명단

**What to build:** 모집 중인 약속의 링크로 들어온 사람이 닉네임·PIN으로 참여자 등록을 하면 바로 로그인된다. 다른 기기에서는 닉네임·PIN을 입력해 같은 참여자로 다시 로그인할 수 있다. 참여자는 명단을 볼 수 있고 로그아웃할 수 있다.

스펙: User Stories 20~35. API: MEMBER-API-03~07.

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 참여자 등록은 collecting에서만 허용한다. draft, closed, confirmed는 거부한다. 마감 시각이 지난 collecting은 closed로 보고 거부한다
- [ ] 같은 약속 안에서 정규화 닉네임이 겹치면(탈퇴자 포함) 409, 정원이 다 찼으면 거부한다
- [ ] 등록에 성공하면 세션 쿠키가 발급되고, 다른 약속의 세션과 섞이지 않는다
- [ ] 재인증(로그인): 닉네임을 정규화한 뒤 PIN 해시를 비교하고, 기기마다 세션을 따로 발급한다(동시 로그인 허용). 실패 제한은 없다
- [ ] 세션은 마감 후 7일에 만료된다. 로그아웃은 행을 지우지 않고 expires_at을 현재 시각으로 바꾼다
- [ ] 내 정보 조회와 명단(닉네임, 방장 표시)은 로그인한 참여자만 볼 수 있다. 비로그인 사용자는 약속 상태만 본다
- [ ] 화면: 참여자 등록 폼, 로그인 폼("PIN을 잊었다면 다른 닉네임으로 새로 참여하세요" 안내), 명단, 로그아웃. 브라우저에서 수동 확인
