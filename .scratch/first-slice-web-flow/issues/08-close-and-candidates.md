# 08: 마감과 후보 공개

**What to build:** 방장이 조기 마감하거나 마감 시각이 지나면 약속이 마감되고 최종 후보가 공개된다. 모집 중에도 참여자들은 현재 제출값 기준의 후보를 실시간으로 본다. 후보마다 참석 가능한 사람의 닉네임이 보이고, 후보가 없으면 안내가 뜬다.

스펙: User Stories 56~66. API: STATE-API-04, 후보 조회. 규칙: STATE-05-01~03, RESULT-08-01, 09-01/02, 10-01.

**Blocked by:** 05, 06

**Status:** ready-for-agent

- [ ] 조기 마감은 방장만, collecting일 때만 할 수 있고 상태를 closed로 바꾼다. 멤버는 거부한다
- [ ] 조기 마감과 제출이 동시에 들어오면 promises 행 잠금 순서로 직렬화되어, 먼저 잠금을 얻은 쪽이 이긴다
- [ ] 참여자 전원이 제출해도 자동으로 마감되지 않는다
- [ ] 후보 조회는 05 모듈로 계산하고, 제출을 마친 active 참여자만 반영한다. 기준 시각은 서버 시각이다
- [ ] 모집 중이든 마감 후든, 로그인한 참여자에게 후보와 후보별 닉네임을 공개한다
- [ ] 후보가 없으면 "2명 이상 겹치는 시간이 없어요"라고 안내한다
- [ ] 화면(Figma 17·18·21): 모집 중에는 "일정 확정하기" 자리에 방장용 "조기 마감" 버튼. 후보 확인(시작·끝, 가능 인원, 닉네임). 히트맵 칸을 누르면 시간 상세 팝업(가능/불가능만, 미응답 구분 없음). 마감 후 읽기 전용 표시. 브라우저에서 수동 확인
