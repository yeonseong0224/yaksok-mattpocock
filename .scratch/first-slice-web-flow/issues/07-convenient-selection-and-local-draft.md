# 07: 편한 선택과 로컬 임시 저장

**What to build:** 참여자가 드래그나 날짜·블록 단위로 슬롯을 빠르게 고를 수 있다. 제출 전 선택은 브라우저에 자동 저장되어 새로고침해도 남는다. 다른 기기에서 더 최신 제출을 했다면 이 기기의 오래된 입력은 버려지고 안내가 뜬다.

스펙: User Stories 37~41, 46~47, 32(로컬 입력 삭제). 규칙: TIME-09-01~04, TIME-10-01~04, TIME-11-02.

- [x] 날짜나 블록을 누르면 설정 범위 안의 슬롯만 선택된다. 일부만 선택된 상태에서 누르면 전체 선택, 전체 선택된 상태에서 누르면 전체 해제
- [x] 일부만 선택된 날짜·블록은 전체 선택과 구별되는 스타일로 표시한다

- [x] 제출하지 않은 수정이 있으면 "제출하지 않은 수정 있음"을 표시한다. 집계에는 기존 제출값이 그대로 쓰인다

- [x] 로그아웃하거나 마감되면 로컬 입력을 지운다

- [x] 반복 기능과 모바일 전용 선택 모드는 이 티켓에 포함하지 않는다(`.scratch/vote-ui-extras/`)
