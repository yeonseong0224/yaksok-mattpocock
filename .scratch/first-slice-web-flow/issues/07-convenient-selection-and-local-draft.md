# 07: 편한 선택과 로컬 임시 저장

**What to build:** 참여자가 드래그나 날짜·블록 단위로 슬롯을 빠르게 고를 수 있다. 제출 전 선택은 브라우저에 자동 저장되어 새로고침해도 남는다. 다른 기기에서 더 최신 제출을 했다면 이 기기의 오래된 입력은 버려지고 안내가 뜬다.

스펙: User Stories 37~41, 46~47, 32(로컬 입력 삭제). 규칙: TIME-09-01~04, TIME-10-01~04, TIME-11-02.

**Blocked by:** 06

**Status:** ready-for-agent

- [ ] 드래그로 여러 슬롯을 한 번에 선택하거나 해제할 수 있다
- [ ] 날짜나 블록을 누르면 설정 범위 안의 슬롯만 선택된다. 일부만 선택된 상태에서 누르면 전체 선택, 전체 선택된 상태에서 누르면 전체 해제
- [ ] 일부만 선택된 날짜·블록은 전체 선택과 구별되는 스타일로 표시한다
- [ ] 드래그가 끝날 때 localStorage(키: 약속ID+참여자ID)에 선택과 기준 version을 저장하고, 제출에 성공하면 지운다
- [ ] 제출하지 않은 수정이 있으면 "제출하지 않은 수정 있음"을 표시한다. 집계에는 기존 제출값이 그대로 쓰인다
- [ ] 폴링으로 받은 서버 version이 로컬의 기준 version과 다르면 로컬 입력을 버리고 최신 값을 보여주며 안내한다. 제출이 409 버전 충돌로 거부돼도 똑같이 처리한다
- [ ] 로그아웃하거나 마감되면 로컬 입력을 지운다
- [ ] 드래그 동작은 Figma 상호작용 규칙을 따른다: 처음 누른 칸이 빈 칸이면 추가, 선택된 칸이면 해제. 사각 범위로 날짜와 시간을 함께 선택. 포인터 캡처를 써서 마우스가 밖으로 나가도 종료 처리
- [ ] 반복 기능과 모바일 전용 선택 모드는 이 티켓에 포함하지 않는다(`.scratch/vote-ui-extras/`)
- [ ] 브라우저에서 수동 확인(새로고침해도 유지되는지, 브라우저 두 개로 충돌 재현)
