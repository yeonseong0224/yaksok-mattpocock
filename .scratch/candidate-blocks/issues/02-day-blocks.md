# 02: 하루 단위 후보

**What to build:** 후보를 "약속 길이 창 5개" 대신 하루 안의 연속된 시간 블록으로 보여준다. 블록 = 날짜마다 2명 이상 가능한 30분 칸이 이어진 구간. 카드에는 날짜, 구간, 약속 길이 내내 함께 가능한 최대 인원(/ 참여자 수), 연속 시간과 배치 가능 여부가 보인다.

**Blocked by:** 01(소요 시간 설정)

**Status:** in progress

- [x] 후보 계산 모듈이 블록과 블록별 최적 창을 계산한다(선택 가능 먼저, 인원 많은 순, 빠른 순, 최대 5개)
- [x] 약속 길이보다 짧거나 내내 함께 가능한 사람이 2명 미만인 블록은 회색 "선택 불가" 카드
- [x] 후보 조회 API가 `durationMinutes`, `blocks[]`를 돌려준다
- [x] 데스크톱 후보 패널, 모바일 서랍이 카드 목록을 보여준다. 방장이 아니면 카드를 누르면 그날 시간표(전체 현황)로 옮긴다
- [ ] 브라우저 수동 확인

## Comments

- 2026-11-17 사용자 결정: "2명 이상 겹치는 구간". 보내주신 HTML의 안내 문구 "모두가 연속으로 비어 있는 구간만"은 이 규칙에 맞게 "하루 안에서 2명 이상 가능한 시간이 이어진 구간"으로 바꿨다.
