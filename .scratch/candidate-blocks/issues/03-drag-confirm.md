# 03: 상세 시간 드래그로 확정

**What to build:** 방장이 마감 뒤 후보 카드를 누르면 아래로 상세가 펼쳐진다(보내주신 m23-inline-detail.html). 30분 칸마다 가능 인원이 보이고, 약속 길이 블록을 위아래로 끌어(또는 칸을 눌러, ↑↓ 키로) 시작 시간을 정한 뒤 "이 시간으로 확정" → 확인 시트 → 확정한다.

**Blocked by:** 02

**Status:** done

- [x] 확정 API는 보여주는 선택 가능 블록 안의 30분 경계 시작, 창이 블록 안, 그 창 내내 2명 이상이면 확정한다. 아니면 409와 새 `blocks`
- [x] 상세에서 고른 창의 시간·인원이 아래 줄에 보이고, 2명 미만이면 확정 버튼이 비활성
- [x] 모바일: 전체 현황의 "약속 확정하기"가 전체 화면 "약속 후보를 골라주세요"를 열고, 확정 줄은 화면 아래 고정
- [x] 데스크톱: 후보 패널에서 같은 카드·상세·확정 버튼
- [x] 히트맵 칸 상세의 "이 시간으로 확정하기"는 그 칸에서 시작하는 창을 확정할 수 있을 때 보인다
- [x] 브라우저 수동 확인
