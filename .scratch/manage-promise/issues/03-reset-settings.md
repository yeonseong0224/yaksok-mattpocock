# 03: 재설정 (모집 중 설정 변경)

**What to build:** 방장이 모집 중에 약속 이름, 날짜 범위, 정원, 마감을 바꾼다. 범위를 줄이면 저장 전에 지워질 입력을 알리고, 저장 후 영향(지워진 슬롯·영향받은 사람·후보 유무)을 보여준다. 범위 확대로 제출 상태가 풀린 사람의 남은 슬롯도 후보 계산에 계속 들어간다(X-07).

스펙: User Stories 1~11. API: STATE-API-03. 규칙: STATE-01-01, 04-01~03, 09-04, TIME-14-03/04, MEMBER-07-03.

**Blocked by:** 02
