# 04: 재조율 (마감·확정 → 다시 모집 중)

**What to build:** 방장이 마감됐거나 확정된 약속을 새 마감과 함께 다시 모집 중으로 돌린다. 날짜 범위와 정원도 함께 바꿀 수 있다. 확정 일정은 해제된다. 후보가 없을 때 방장은 안내에서 바로 재조율이나 취소를 고른다.

스펙: User Stories 12~17. API: STATE-API-06. 규칙: STATE-09-01~05, RESULT-08-02.

**Blocked by:** 02, 03 (설정 폼 재사용)

**Status:** done

- [x] `POST /promises/{id}/reopen`: 방장만, closed·confirmed만. `votingDeadlineAt` 필수, 날짜 범위·정원 선택. 02 모듈로 검증·영향 반영
- [x] 상태를 collecting으로, `confirmed_start_at`을 비운다. 세션을 새 마감 + 7일로 맞춘다
- [x] 다시 열리면 빈자리가 있을 때 새 참여를 받는다
- [x] 확정 결과 화면·마감 화면에서 방장에게 "다시 조율하기" → 설정 폼(마감 필수)
- [x] 후보 없음 안내에 방장에게 "다시 조율하기"·"약속 취소"(취소는 05가 끝나면 연결) — 다시 조율하기만 연결, 취소는 05
- [x] 참여자는 다시 모집 중이 된 화면에서 입력을 고칠 수 있다(범위 안 기존 선택 유지). 브라우저에서 수동 확인
