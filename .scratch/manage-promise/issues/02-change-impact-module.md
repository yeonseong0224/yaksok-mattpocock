# 02: 설정 변경 영향 계산 모듈

**What to build:** 재설정과 재조율이 함께 쓰는 순수 모듈. 이전·새 설정(날짜 범위, 정원, 마감)과 active 참여자별 슬롯·제출 여부, 서버 시각을 받아 지울 슬롯, 버전을 올릴 참여자, 제출 상태를 풀 참여자, 검증 오류를 돌려준다. DB와 시계에 의존하지 않는다.

스펙: 「모듈 / 설정 변경 영향 계산」. 규칙: STATE-04-02, 09-03, 09-04, MEMBER-07-03, TIME-04-01~03, TIME-14-01~04.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 새 범위 밖 슬롯은 지우고 안쪽은 유지한다. 슬롯이 실제로 지워진 참여자만 버전 +1
- [ ] 고를 수 있는 슬롯이 하나라도 늘면(확대·이동) active 전원 제출 상태 해제 + 버전 +1. 줄기만 하면 제출 상태 유지
- [ ] 이름·정원·마감만 바뀌면 슬롯·버전·제출 상태 그대로
- [ ] 정원 2~30, active 인원 미만이면 `CAPACITY_BELOW_ACTIVE_COUNT`
- [ ] 날짜 범위: 새로 고르는 시작일은 오늘(KST)부터, 양 끝 포함 최대 90일. 이미 지난 기존 시작일을 그대로 두는 것은 허용
- [ ] 마감: 지금+30분 이상, 범위 마지막 날 00:00 KST 미만. 연장·단축 모두 허용
- [ ] 위 규칙을 표 형태 단위 테스트로 검증한다
