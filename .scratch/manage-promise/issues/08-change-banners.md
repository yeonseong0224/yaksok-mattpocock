# 08: 변경 알림 배너

**What to build:** 방장의 재설정·재조율, 범위 확대로 풀린 제출 상태, 방장 승계를 참여자가 다음에 화면을 볼 때 배너로 한 번 알린다. DB를 바꾸지 않고, 브라우저가 약속별로 마지막으로 본 상태와 비교한다.

스펙: 「화면 / 배너」, User Stories 9·10·16·28. 규칙: STATE-04-03, 09-03, 09-04, MEMBER-12-01.

**Blocked by:** 03, 04, 06

**Status:** done

- [x] 마지막으로 본 상태(설정, 약속 상태, 내 역할, 내 슬롯 수, 내 제출 여부)를 약속·참여자별로 브라우저에 저장한다. localStorage가 막혀도 화면은 동작한다
- [x] 이전·현재 상태로 띄울 배너를 고르는 순수 함수와 단위 테스트
  - 설정 변경 → "방장이 설정을 바꿨어요"(내 입력이 지워졌으면 함께)
  - 범위 확대로 제출 상태 해제 → "고를 수 있는 시간이 늘었어요. 다시 확인하고 제출해 주세요."
  - 재조율 → "다시 조율 중이에요"
  - member → host → "방장 권한을 넘겨받았어요"
- [x] 배너는 닫을 수 있고, 한 번 보면 다시 뜨지 않는다. 처음 방문(저장된 상태 없음)에는 띄우지 않는다
- [x] 방장 본인의 변경에는 띄우지 않는다(본인이 저장 직후 이미 안내를 봄)
- [x] 데스크톱·모바일에서 브라우저 수동 확인
