# 02: 모바일 시간 선택

**What to build:** 카카오톡 링크로 들어온 모바일 사용자가 터치로 가능 시간을 고른다. 주간표는 가로로 스크롤하고, 선택 모드와 스크롤 모드를 전환할 수 있다. 선택 모드에서는 드래그하면 칸이 선택되고, 스크롤 모드에서는 화면이 움직인다. 반복 기능은 우클릭 대신 반복 버튼이나 날짜 더보기로 열고, 바텀시트에서 주간 반복과 특정 날짜 반복 중 하나를 고른다.

디자인: `docs/design/FIGMA.md`의 23·24 화면.

## Comments

- 2026-11-11 사용자 결정
  - 모바일에서 날짜(머리글)나 시간 슬롯을 2초 동안 누르고 있으면 그 날짜의 반복 바텀시트가 열린다(데스크톱 우클릭에 해당). 티켓의 "날짜 더보기" 대신이다.
  - 하단 "반복 사용" 버튼은 모바일에서만 보인다. 원본 날짜가 정해지지 않으므로 시트에서 시간을 고른 날짜부터 고른 뒤 주간·특정 날짜 반복을 고른다("다른 날짜 고르기"로 되돌아갈 수 있다).
- 구현 메모(`feat/mobile-time-selection`). 화면은 수동 확인 완료(2026-11-11).
  - 선택·스크롤 모드 전환은 화면 폭이 아니라 터치 기기(`pointer: coarse`)에서 보인다. 태블릿처럼 넓은 터치 화면에서도 모드를 바꿀 수 있게 하려고.
  - 선택 모드에서만 슬롯이 `touch-action: none`이라 터치 드래그가 선택이 되고, 스크롤 모드에서는 터치로 슬롯을 바꾸지 않고 화면이 움직인다. 날짜·오전·오후·저녁 버튼은 두 모드 모두 누르면 고르거나 푼다.
  - 선택 모드에서 슬롯을 2초 누르면, 누르는 동안 미리 보이던 선택은 취소되고 시트가 열린다. 10px 넘게 움직이면 길게 누르기가 아니라 드래그로 본다.
  - Android의 길게 누르기 contextmenu는 막고, 2초 기준으로만 연다. 길게 누른 뒤 손을 뗄 때의 click은 날짜 선택이나 시트 닫기로 처리하지 않는다.
  - 모바일에서는 "반복 사용"과 "가능 시간 제출"이 화면 아래에 고정된다(Figma 23 "하단 제출 버튼은 항상 접근 가능"). 후보 보기·조기 마감은 기존 하단 바에 남는다.
