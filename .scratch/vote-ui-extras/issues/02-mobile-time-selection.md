# 02: 모바일 시간 선택

**What to build:** 카카오톡 링크로 들어온 모바일 사용자가 터치로 가능 시간을 고른다. 주간표는 가로로 스크롤하고, 선택 모드와 스크롤 모드를 전환할 수 있다. 선택 모드에서는 드래그하면 칸이 선택되고, 스크롤 모드에서는 화면이 움직인다. 반복 기능은 우클릭 대신 반복 버튼이나 날짜 더보기로 열고, 바텀시트에서 주간 반복과 특정 날짜 반복 중 하나를 고른다.

디자인: `docs/design/FIGMA.md`의 23·24 화면.

**Blocked by:** first-slice-web-flow 07 (편한 선택과 로컬 임시 저장), vote-ui-extras 01 (반복 바텀시트 부분만)

**Status:** ready-for-agent

- [ ] 모바일 화면 폭에서 주간표를 가로로 스크롤할 수 있다
- [ ] 선택 모드와 스크롤 모드를 전환할 수 있다. 선택 모드에서는 터치 드래그로 칸을 선택하거나 해제하고(규칙은 데스크톱 드래그와 같다), 스크롤 모드에서는 화면이 움직인다
- [ ] 반복 버튼이나 날짜 더보기를 누르면 바텀시트가 열리고, 주간 반복과 특정 날짜 반복을 고를 수 있다(01의 기능을 재사용)
- [ ] 제출, 로컬 임시 저장, 버전 충돌 처리는 데스크톱과 똑같이 동작한다
- [ ] 실제 모바일 기기나 브라우저의 모바일 에뮬레이션에서 수동 확인
