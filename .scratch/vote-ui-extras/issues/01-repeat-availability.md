# 01: 가능 시간 반복 적용

**What to build:** 참여자가 한 날짜에 고른 가능 시간을 다른 날짜에 복사해 빠르게 입력한다. 날짜 열이나 선택 블록을 우클릭하면 반복 메뉴가 열리고, 두 가지 방식 중 하나를 고른다.

- **주간 반복**: 요일과 반복 종료일을 고르면 대상 날짜와 시간을 미리 보여준 뒤 적용한다.
- **특정 날짜 반복**: 달력에서 날짜를 여러 개 고른 뒤 적용한다.

적용 결과는 제출 전 로컬 선택에만 더해지고, 제출해야 서버에 반영된다. 서버 규칙과 API는 바뀌지 않는 클라이언트 전용 기능이다.

디자인: `docs/design/FIGMA.md`의 09~12 화면, 상호작용 규칙의 "반복 적용"과 "우클릭 / 모바일".

- [x] 날짜 범위 밖이나 이미 지난 슬롯은 대상에서 빠진다. 기존 선택과는 합집합으로 합친다
- [x] 적용 결과는 로컬 임시 저장(first-slice 07)에 반영되고, "제출하지 않은 수정 있음"이 표시된다
- [x] 반복 대상 계산은 순수 함수로 만들고 단위 테스트로 검증한다. 화면은 브라우저에서 수동 확인

## Comments

- 구현 메모(2026-11-11, `feat/repeat-availability`). 화면은 브라우저에서 수동 확인 완료.
  - 반복 계산은 `lib/availability/repeat.ts`의 순수 함수(`planRepeat`, `weeklyDates`, `slotRanges`)로 두고 단위 테스트로 검증한다. 화면은 결과를 `applySelection(…, add)`로 내 선택에 더하므로 로컬 임시 저장과 "제출하지 않은 변경이 있어요" 표시를 그대로 탄다.
  - 주간 반복은 원본 날짜 다음 날부터 종료일까지다(원본보다 앞 날짜는 넣지 않는다). 종료일 기본값은 날짜 범위 마지막 날, 요일 기본값은 원본 날짜의 요일.
  - 대상에서 빼는 것: 원본 날짜, 날짜·하루 시간 범위 밖, 지난 슬롯(serverTime 기준), 이미 고른 슬롯. 새로 더해질 시간이 없는 날짜는 개수와 미리보기에서도 빠진다.
  - 미리보기는 "N개 날짜에 추가 · 10/13, 10/20…"에 더해 날짜별로 실제로 더해질 시간을 5개까지 보여 준다(지난 시간 때문에 일부만 들어가는 날짜를 구분하려고).
  - 우클릭은 날짜 열의 머리글이나 칸 어디서든 그 날짜의 메뉴를 연다. 키보드는 메뉴 키·Shift+F10으로 열고, 화살표로 항목을 옮긴다. 바깥을 누르면 닫기만 하고 그 누름으로 칸이 바뀌지 않는다.
  - 하단 "반복 사용" 버튼(Figma 09·12)은 모바일 진입점(02)과 함께 다룬다.
