# 01: 가능 시간 반복 적용

**What to build:** 참여자가 한 날짜에 고른 가능 시간을 다른 날짜에 복사해 빠르게 입력한다. 날짜 열이나 선택 블록을 우클릭하면 반복 메뉴가 열리고, 두 가지 방식 중 하나를 고른다.

- **주간 반복**: 요일과 반복 종료일을 고르면 대상 날짜와 시간을 미리 보여준 뒤 적용한다.
- **특정 날짜 반복**: 달력에서 날짜를 여러 개 고른 뒤 적용한다.

적용 결과는 제출 전 로컬 선택에만 더해지고, 제출해야 서버에 반영된다. 서버 규칙과 API는 바뀌지 않는 클라이언트 전용 기능이다.

디자인: `docs/design/FIGMA.md`의 09~12 화면, 상호작용 규칙의 "반복 적용"과 "우클릭 / 모바일".

**Blocked by:** first-slice-web-flow 07 (편한 선택과 로컬 임시 저장)

**Status:** ready-for-agent

- [ ] 날짜 열이나 선택 블록을 우클릭하면 반복 메뉴가 열린다. 선택이 없는 빈 날짜에서는 비활성이다. Esc나 바깥 클릭으로 닫히고 포커스가 원래 자리로 돌아간다
- [ ] 주간 반복: 요일과 반복 종료일을 고르면 대상 날짜와 시간을 미리 보여주고, 적용하면 복사된다
- [ ] 특정 날짜 반복: 월을 이동하며 여러 날짜를 토글로 고른 뒤 적용한다. 원본 날짜는 대상에서 빠진다
- [ ] 날짜 범위 밖이나 이미 지난 슬롯은 대상에서 빠진다. 기존 선택과는 합집합으로 합친다
- [ ] 적용 결과는 로컬 임시 저장(first-slice 07)에 반영되고, "제출하지 않은 수정 있음"이 표시된다
- [ ] 반복 대상 계산은 순수 함수로 만들고 단위 테스트로 검증한다. 화면은 브라우저에서 수동 확인
