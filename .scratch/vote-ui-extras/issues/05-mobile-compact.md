# 05: 모바일 화면 다듬기(설정 화면·☰·길게 누르기·781px)

**What to build:** 모바일에서 방장 설정 화면을 확대·축소 없이 보게 하고, ☰를 눈에 띄게, 반복 길게 누르기를 1초로 바꾸고, 모든 모바일 화면을 아이폰 16보다 세로 1/12 짧은 화면(393×781)에 맞춘다.

**Blocked by:** 없음

**Status:** done

- [x] 입력칸·선택 상자 글자를 모바일(sm 미만)에서 16px로 둔다. iOS가 16px보다 작은 입력칸을 누르면 화면을 확대하기 때문이다(데스크톱은 14px 그대로)
- [x] 모바일 설정 화면의 제목·간격·미리보기·달력 칸·안내 문구를 줄인다(데스크톱 그대로)
- [x] 상단바는 원래 크기 그대로, ☰만 연한 파란 둥근 사각형(테두리 없이 바탕색 하나, 파란 아이콘)으로 감싼다
- [x] 날짜·시간을 길게 눌러 반복 시트를 여는 시간 2초 → 1초
- [x] 기준 높이 781px: 시간표 화면 위 조작 줄(탭·주 이동·모드) 높이를 줄여 격자가 더 보이게 한다. 시트·서랍·후보 화면은 그 높이에서 안에서 스크롤되고 버튼이 잘리지 않는다
- [x] 브라우저 수동 확인

## Comments

- 2026-11-18 사용자 요청. 375px에서 가로로 넘치는 요소는 없었다. 그래서 "줌아웃해야 한다"는 원인은 iOS 입력칸 자동 확대와 화면 크기로 보고 둘 다 고쳤다.
- 2026-11-18 사용자 결정: 상단바 2/3는 되돌리고 ☰를 파란 둥근 사각형으로. "세로 1/12"는 "781px 높이에 맞추기"(글자 크기 그대로, 필요한 곳만 줄임).
- 2026-11-18: ☰ 색을 덜 쨍하게(진한 파랑 → 연한 파랑 바탕) 바꿨다. 화면은 수동 확인 완료.
- 2026-11-18: ☰ 테두리 색을 바탕과 같게 통일(테두리 없앰).
