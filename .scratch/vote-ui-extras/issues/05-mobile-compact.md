# 05: 모바일 설정 화면 줄이기와 상단바 2/3

**What to build:** 모바일에서 방장 설정 화면(새 약속 만들기)을 확대·축소 없이 볼 수 있게 줄이고, 상단바("✓ 약속 잡기") 높이와 글자를 2/3로 줄인다.

**Blocked by:** 없음

**Status:** in progress

- [x] 입력칸·선택 상자 글자를 모바일(sm 미만)에서 16px로 둔다. iOS가 16px보다 작은 입력칸을 누르면 화면을 확대하기 때문이다(데스크톱은 14px 그대로)
- [x] 모바일 설정 화면의 제목·간격·미리보기·달력 칸·안내 문구를 줄인다(데스크톱 그대로)
- [x] 상단바 높이 64px → 44px, 로고 글자 18px → 12px, ☰ 버튼도 맞춰 줄인다. 모바일 시간표 높이 계산과 후보 고르기 화면 머리도 맞춘다
- [ ] 브라우저 수동 확인

## Comments

- 2026-11-18 사용자 요청. 375px에서 가로로 넘치는 요소는 없었다. 그래서 "줌아웃해야 한다"는 원인은 iOS 입력칸 자동 확대와 화면 크기로 보고 둘 다 고쳤다.
- 상단바 2/3는 모든 화면 폭에 적용했다(데스크톱 포함).
