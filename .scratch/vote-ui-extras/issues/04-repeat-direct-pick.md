# 04: 반복 — 시간과 날짜를 직접 고르기

**What to build:** 모바일 "반복" 버튼을 누르면 복사할 원본 날짜 목록 대신, 넣을 시간(시작~종료 구간 여러 개)과 날짜(매주 요일 + 기간, 또는 달력에서 여러 날짜)를 직접 고르는 바텀시트가 열린다. 적용하면 고른 날짜마다 그 시간이 제출 전 선택에 합집합으로 더해진다.

**Blocked by:** vote-ui-extras 03

**Status:** done

- [x] "반복" 버튼은 고른 시간이 없어도 누를 수 있고, 시간 구간을 추가·수정·삭제할 수 있다(처음 값: 가장 이른 고른 날짜의 시간, 없으면 18:00~20:00)
- [x] 날짜는 "매주 요일로"(요일 + 시작일~종료일, 양 끝 포함) 또는 "달력에서"(여러 날짜 토글, 오늘~범위 끝) 중 하나로 고른다
- [x] 미리보기에 더해질 날짜 수와 날짜가 보이고, 이미 고른 시간·지난 시간·범위 밖은 빠진다
- [x] 데스크톱 우클릭 메뉴와 모바일 길게 누르기(원본 날짜 복사)는 그대로다
- [x] 브라우저 수동 확인
